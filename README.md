# MiniBank

Backend-сервіс для керування рахунками, балансами та транзакціями. Підтримує поповнення, списання й перекази коштів, паралельну обробку операцій та щоденні знімки балансу.

## Можливості

- Реєстрація користувачів і створення рахунків.
- Отримання поточного балансу та балансу на визначену дату.
- Поповнення рахунку, списання коштів і перекази між рахунками.
- Асинхронна обробка транзакцій кількома воркерами.
- Перевірка достатності коштів і відстеження статусів операцій.
- Ідемпотентність запитів для запобігання повторним операціям.
- Щоденні знімки балансу за розкладом.
- Перегляд транзакцій та їхніх результатів через REST API.

## Технології та архітектура

Java 21, Spring Boot, Spring Data JPA, H2, Flyway, Maven.

Застосунок розділений на доменну модель, прикладні сценарії та інфраструктуру. Вхідні й вихідні порти відокремлюють бізнес-логіку від контролерів і зберігання даних.

## Запуск

```bash
./mvnw spring-boot:run
```

У Windows: `mvnw.cmd spring-boot:run`.

Застосунок використовує вбудовану H2 у пам’яті, тому окремий сервер бази даних не потрібен. Дані очищаються після зупинки застосунку. HTTP-порт за замовчуванням — `8080`.

## Тести

Модульні та інтеграційні тести без навантажувального сценарію:

```bash
./mvnw "-Dtest=*Test,*IT,!SystemLoadTest" test
```

Повний набір із навантажувальним сценарієм:

```bash
./mvnw "-Dtest=*Test,*IT" test
```

Навантажувальний тест моделює 50 користувачів із 500 операціями для кожного та перевіряє результати обробки транзакцій.
